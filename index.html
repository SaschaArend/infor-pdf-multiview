Neu: E-Rechnung & ZUGFeRD Suite

Bereit für die E-Rechnungspflicht – direkt in Infor LN.

Egal ob eine reine XML-Datei (XRechnung) im IDM archiviert wurde oder eine hybride PDF/A-3 (ZUGFeRD / Factur-X) geöffnet wird: Die Erweiterung erkennt und prüft strukturierte Rechnungsdaten vollautomatisch im Hintergrund.

HYBRID PDF/A-3 EXTRACTOR

Lautlose XML-Tiefenanalyse in jedem PDF

Sobald ein PDF geladen wird, durchsucht extractXmlFromPdfBytes() die Datei im Hintergrund nach eingebetteten XML-Streams – selbst wenn diese per FlateDecode komprimiert sind (über die native Browser-DecompressionStream API).

Wird ein ZUGFeRD/Factur-X-Datensatz erkannt, erscheint am unteren Rand automatisch die 3-Wege-Umschaltleiste: Original-PDF, E-Rechnung (DIN-A4 Visualisierung) und XML-Code. Normale PDFs bleiben völlig unverändert.

✓ Original-PDF ✓ E-Rechnung (EN 16931) ✓ XML-Quelltext & Suche factur-x.xml Export
EN 16931 & BR-DE VALIDATOR

Mathematische & formale Regelprüfung

Jede erkannte E-Rechnung wird sofort gegen die europäischen EN 16931 Business Rules sowie deutsche XRechnung-Regeln (BR-DE) geprüft. Ein Klick auf Prüfprotokoll zeigt alle Ergebnisse im Detail:

Neben Pflichtfeldern wie Leitweg-ID/Käuferreferenz (BT-10), USt-IdNr. (BT-31) und Verkäuferkontakt (BR-DE-2) rechnet die Engine alle Positionsnettobeträge, Steuerbasen und Bruttosummen auf den Cent genau nach.

BR-01 Profil (BT-24) BR-CO-10 Positionssumme = Netto BR-CO-15 Netto + MwSt = Brutto BR-DE-15 Leitweg-ID
VISUELLER BELEG-GENERATOR

Aus trockenem XML wird ein druckfertiger A4-Beleg

Reine XML-Rechnungen (application/xml, text/xml) sind für Sachbearbeiter im Rohformat kaum lesbar. Der integrierte Renderer übersetzt sowohl UN/CEFACT CII als auch OASIS UBL 2.1 (Rechnungen & Gutschriften) in ein übersichtliches Rechnungsformular inklusive Druck-/PDF-Speicherfunktion.

02 • MAGIC-BYTE INSPECTOR

Präzise Signatur-Erkennung

Da ein abgeleiteter /resource/stream-Endpunkt sowohl PDFs, XML-Rechnungen als auch Office-Dateien liefern kann, prüft content.js die ersten Bytes des Streams (%PDF, PK, <?xml) vor dem Rendering.

const isZip = bytes[0] === 0x50 && bytes[1] === 0x4B;
const isPdf = bytes[0] === 0x25 && bytes[1] === 0x50;
const isXml = !isZip && !isPdf && (
  head.startsWith('<?xml') ||
  head.includes('CrossIndustryInvoice')
);
03 • FLATEDECODE DECOMPRESSION

Eingebettete PDF/A-3 Streams entpacken

Hybride ZUGFeRD-PDFs speichern die factur-x.xml meist komprimiert in einem PDF-Objektstream. Die Erweiterung entpackt FlateDecode-Blöcke direkt im Speicher mittels DecompressionStream.

const ds = new DecompressionStream('deflate');
const writer = ds.writable.getWriter();
writer.write(rawSlice);
writer.close();
const xml = await new Response(ds.readable).text();
